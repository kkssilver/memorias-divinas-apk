COMO JOGAR

WASD mover · Shift passos silenciosos · Mouse: segure para armar o arco, solte para atirar

Espaço lançar pedra · F (segure) escutar o vento · E interagir · Q acender a flecha na fogueira · P pausar

Toque e arraste na metade esquerda para mover. Na metade direita, segure e arraste para mirar; solte para atirar. Os botões à direita: Pedra, Agir (interagir), Fogo, Impulso, Ouvir e Passo leve. ❚❚ pausa.

O vento leva flechas, cheiros e vozes. Caçadores seguem o som e o cheiro — e voltam para onde estavam quando se cansam.

Há três selos de espinhos no bosque. Cada um pede uma habilidade diferente.

Use fones. Toque para fechar.
